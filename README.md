# 文章收藏助手（wzsc-collector）

在浏览器里点一下，把正在看的文章（正文 + 图片 + 精选评论）存成 Markdown，
丢进你自己的收藏仓库。支持**知乎 / 微信公众号 / 微博 / X / 任意网页**。

**服务跟着浏览器走**：浏览器开着的时候，本机服务在后台默默待命（点扩展秒开，
没有任何窗口）；浏览器全关一会儿，它自己就退出了。

## 它是怎么工作的

| 部分 | 干什么 |
| --- | --- |
| 浏览器扩展 | 抓正文、滚动加载评论、点开"阅读全文"，然后把内容交给本机服务 |
| `启动收藏助手.vbs`（看门狗，开机启动、隐藏窗口） | 浏览器开着就保证本机服务在待命；服务意外退出会自动拉回来 |
| `src/server.js`（本机服务） | 把内容写成 `编号.标题.md`；浏览器全关 3 分钟后自己退出 |
| `bin\wzsc-host.exe`（小助手，7 KB） | 兜底用：万一服务没在跑（比如刚开机），扩展点一下就能立刻唤醒它 |

看门狗挂在开机启动里，所以开机后照常开浏览器就行；
小助手走的是 Chrome / Edge 官方的**原生消息（Native Messaging）**通道——
这是浏览器唯一允许扩展启动本机程序的方式。安装时会在
`HKEY_CURRENT_USER\Software\Microsoft\Edge\NativeMessagingHosts\` 等位置登记一条记录（只改当前用户）。

登录状态用的是**你自己浏览器**的登录态，所以知乎评论、微博、X 回复都能正常拿到，
不需要额外登录什么。

## 安装（只做一次）

1. **装 Node.js**（已装可跳过）：<https://nodejs.org> 下载 LTS 版，一路下一步。
2. **双击 `1-一键安装.cmd`**
  它会自动：记下 Node 位置 → 检查配置 → 装依赖 → 用 Windows 自带的编译器生成小助手 →
   登记到 Edge / Chrome / Brave → 加入开机启动（看门狗）→ 试跑一次确认服务已待命。
3. **在浏览器里重新加载扩展**（因为扩展 ID 固定了，必须做一次）：
   - Edge 打开 `edge://extensions`（Chrome 是 `chrome://extensions`）
   - 如果还能看到「文章收藏助手」，先点**移除**
   - 打开**开发人员模式** → 点**加载解压缩的扩展** → 选本文件夹

## 日常使用

- **收藏一篇文章**：打开文章 → 点右上角扩展图标 → **保存这篇文章**
  （第一次点会多等一两秒，那是在叫醒服务；保存时页面会自己滚动、展开评论，属于正常现象）
- **看存到哪儿了**：扩展里点「打开收藏仓库文件夹」
- **补录公众号留言**：公众号评论只能在微信里看到。把留言复制出来 →
  扩展里展开「补录微信公众号的留言」→ 填文章编号（例如 `478`）→ 粘贴 → 写入

## 设置（`config.json`）

安装时如果还没有 `config.json`，会自动生成一份；用记事本就能改：

| 字段 | 说明 | 默认 |
| --- | --- | --- |
| `repoPath` | 收藏仓库文件夹（md 写到这里） | 桌面 `WenZhangShouCang` |
| `images` | `keep-remote` 只保留图片外链（仓库最小）/ `download` 把图片下载进仓库 | `keep-remote` |
| `includeComments` | 是否采集评论 | `true` |
| `commentFilter` | `author` 只留精选和与作者有互动的 / `all` 全留 / `none` 不留 | `author` |
| `video` | `poster` 只存封面图 + 视频地址 / `none` 不存 | `poster` |
| `maxComments` | 每篇最多保留多少条评论 | `50` |
| `assetsDirName` | 下载图片时的目录名（`keep-remote` 时用不到） | `assets` |

想让服务多待一会儿（默认闲置 5 分钟退出），可以在启动前设环境变量 `WZSC_IDLE_MS`。

## 出问题了

| 现象 | 怎么办 |
| --- | --- |
| 扩展提示"没连上本机服务" | 先双击 `1-一键安装.cmd` 重装一次（会打印登记和启动是否成功） |
| 想看看门狗在干什么 | 打开 `debug\watchdog.log`（每次它检查/启动服务都会记一行） |
| 杀毒软件询问 `bin\wzsc-host.exe` | 允许即可，它就是这个 7 KB 的启动小助手 |
| 把项目文件夹改名或移动了 | 重新双击 `1-一键安装.cmd`（登记的路径要跟着更新） |
| 抓出来的排版/评论不对 | 在扩展里勾「同时保存调试页面」再存一次，项目里会出现 `debug/`，把快照发我 |
| 自检 | `node src/server.js --check`（看仓库路径、版本、闲置时间、当前有没有服务在跑） |

## 不想要了

双击 `2-取消安装.cmd`：服务会退出、浏览器登记会被删除、旧版本留下的开机启动项也会清掉。
扩展本身不受影响。

## 隐私与安全

- 采集到的东西只写进**你自己的**收藏仓库文件夹，不上传任何地方。
- 登录态在你自己浏览器的配置里，本项目里没有任何账号信息。
- 只登记当前用户（HKCU）的一条原生消息记录，随时可以删。
- `.gitignore` 已排除 `config.json`、`debug/`、`node_modules/`、`bin/`、`node-path.txt`。
